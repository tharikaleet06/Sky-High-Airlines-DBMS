# Data Population

## Overview

This section contains sample SQL `INSERT` statements used to populate the **Sky High Airlines** database.

The original project was executed using Oracle SQL with a larger set of realistic records. However, the complete original data population script is not currently available.

Therefore, this repository includes representative sample `INSERT` statements based on the available project documentation and execution outputs.

## Tables Populated

Sample data is provided for the following tables:

- AIRCRAFT
- AIRPORT
- USER_ACCOUNT
- PASSENGER
- FLIGHT
- SEAT
- BOOKING
- PAYMENT

## Purpose of the Sample Data

The sample records demonstrate the relationships between the different entities in the database.

For example:

- Aircraft are assigned to flights.
- Airports are used as flight sources and destinations.
- User accounts are associated with passengers.
- Flights contain seat information.
- Passengers can create bookings.
- Bookings are associated with payment records.

## Note

The `sample_inserts.sql` file contains representative sample records from the project documentation.

The original project was populated with a larger dataset during implementation in Oracle. Since the complete original insert script is not currently available, only sample records are included in this repository.

These sample queries are provided to demonstrate the database structure and relationships between the tables.
